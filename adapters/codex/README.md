# MALTS 2.0.0 for Codex

## Entry and responsibilities

The Codex adapter supplies native instructions/workflow discovery. The shared v2 services own Task state, authorization scopes, evidence and recovery. The tool-local .codex/MALTS_BOOT.md resolves the installed runtime; discovery checks registry, active pointer, identity and VERSION.

## Installation and use

Follow [Installation](../../docs/INSTALL.md) and [Usage](../../docs/USAGE.md). Reload the Host and verify actual Skills/MCP. Existing personal content outside marked MALTS blocks is retained. New long workspaces must be Phase-ready; existing adopted workspaces continue through current bindings and Task services.



## Verified scope and limitations

Representative Task, cold continuation and selected topic/profile evidence; requested labels are not authenticated effective-model identity. Configuration, installation, effective execution identity and business acceptance remain separate. Single Agent is the default. Delegation, paid calls and publication need their corresponding authorized scope. Unknown effects and cancelled/paused Hosts require reconciliation before continuation.
