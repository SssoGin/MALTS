# MALTS 2.0.0 for OpenCode

## Entry and responsibilities

The OpenCode adapter supplies native instructions/workflow discovery. The shared v2 services own Task state, authorization scopes, evidence and recovery. The tool-local .config/opencode/MALTS_BOOT.md resolves the installed runtime; discovery checks registry, active pointer, identity and VERSION.

## Installation and use

Follow [Installation](../../docs/INSTALL.md) and [Usage](../../docs/USAGE.md). Reload the Host and verify actual Skills/MCP. Existing personal content outside marked MALTS blocks is retained. New long workspaces must be Phase-ready; existing adopted workspaces continue through current bindings and Task services.



## Verified scope and limitations

Representative native Task/cold recovery at 1.17.18; reported usage is not billing or cross-Host causal evidence. Configuration, installation, effective execution identity and business acceptance remain separate. Single Agent is the default. Delegation, paid calls and publication need their corresponding authorized scope. Unknown effects and cancelled/paused Hosts require reconciliation before continuation.
