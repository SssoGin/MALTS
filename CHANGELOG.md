# Changelog

## 1.0.0

- Introduced immutable-generation lifecycle installation for Codex, Claude Code,
  and OpenCode.
- Added project-control, task-report, and handoff templates with EN and
  Simplified Chinese runtime material.
- Added MALTS-native skills for project initialization, preflight, long-task
  coordination, retrospective growth, and session handoff.
- Made long-project workspace initialization phase-ready: the first active
  Phase is required for completion, legacy minimal skeletons are diagnosed for
  no-overwrite migration, and Sessions remain explicit.
- Added capability catalog, routing, and projection support for the three
  selected tools.
- Added review-first planning, hash-bound execution, recovery, and residue
  checks for lifecycle operations.
- Added user package verification before extraction and installation.

## Earlier versions

The 0.1.x series established the reusable runtime, three-tool adapters, shared
skill conventions, and project-control workflow that MALTS v1.0 consolidates.
