# MEMORY_WRITE_CHECKLIST

> 写入长期 Skill、`AGENTS.md`、`CLAUDE.md`、等价工具指令入口或全局记忆前使用。

通过本检查清单只表示候选质量合格，不代表已经取得写入权限。L1 只分析，不写 durable state；L2 只能在一次性项目授权和声明文件面内写入；任何 L3 全局/规范记忆、Skills、checklists、lint、adapters、三工具安装态、公开内容或持久工具指令的提议或修改，都必须另行取得明确确认。

## 权限

- [ ] 已分类为 L1 Analyze / L2 Project Maintain / L3 System Promote。
- [ ] L2 写入记录了项目授权引用，并且没有越出声明文件面。
- [ ] 任何 L3 提议或写入都有单独的明确确认。

## 事实检查

- [ ] 经验真实发生。
- [ ] 来源明确：项目事件、错误、验证、决策或用户反馈。
- [ ] 事实、判断和假设已区分。
- [ ] 缺失信息已标记，而不是编造。

## 复用价值

- [ ] 类似场景未来可能再次出现。
- [ ] 能减少返工、错误、验证缺口或沟通成本。
- [ ] 收益高于流程成本。
- [ ] 不是一次性局部细节。

## 规则质量

- [ ] 有明确触发条件。
- [ ] 有具体执行动作。
- [ ] 有验证或检查方法。
- [ ] 有适用边界。
- [ ] 说明了要避免的风险或复用的实践。

## 去重

- [ ] 已检查现有 Skills。
- [ ] 如相关，已检查 `AGENTS.md` / `CLAUDE.md` / 等价工具指令入口。
- [ ] 不是用不同说法重复已有规则。
- [ ] 如果已有相似规则，应合并或优化，而不是新增一份。

## 去向判断

| 去向 | 使用场景 |
|---|---|
| 当前复盘 | 只对本项目有用 |
| 项目 Skill | 对本项目类似任务可复用 |
| 全局 Skill | 跨项目可复用 |
| `GLOBAL_MEMORY.md` | 跨项目稳定规则、模式或决策 |
| 工具指令文件候选 | 高频、稳定、跨任务行为，适合写入 `AGENTS.md`、`CLAUDE.md` 或等价工具指令入口 |
| 工具适配文档 | 只适用于 Claude Code、Codex、OpenCode 或其他工具 |
| 不写入 | 太具体、未验证、重复或低价值 |

## 安全

- [ ] 没有写入密钥、令牌、账号或敏感本地细节。
- [ ] 用户敏感信息没有提升到全局记忆。
- [ ] 规则不会导致未来不安全自动化。
- [ ] 任何 L3 提议或规则变更都需要用户单独确认。

## Future-Use Validation

- [ ] 已记录原始触发事件，但没有把它计为 future use。
- [ ] `VALIDATED` 已有两个 helped future tasks，task ID 与 independence key 均不同；连同原事件累计三次验证。
- [ ] 高风险候选还有独立审阅或负面/反例测试。
- [ ] 已记录采用、拒绝、延后及 outcome；检索本身不等于应用授权。
- [ ] harmful evidence 进入 `CHALLENGED`；严重 harmful evidence 进入 `SUSPENDED` 并停止自动应用。
- [ ] 存在挑战、修订、废弃、替换和移除路径。

## 降级保存

- [ ] 如果目标长期记忆服务、全局 Skill 路径或持久规则目标不可用，候选已保留在 `PROJECT_CONTROL`、工作任务报告或本地复盘记录中，而不是直接丢失。
- [ ] 面向用户的报告区分了“候选建议”“本地降级记录”和“真实长期写入”。
