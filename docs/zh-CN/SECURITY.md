# 安全

安全和隐私适用于 MALTS 整体工作流、安装与分发。当前版本 **2.0.2**。

## 使用前核验

核实际仓库/ref、VERSION、发布身份及闭合清单。解压前核 ZIP；通过工具 Boot、registry/pointer 发现安装。名称与旧回执不是当前完整性检查。

同时核来源和当前字节。可信仓库名称不证明本地 checkout 完整，也不证明解压归档路径安全。生命周期在激活前核声明清单并拒绝意外内容，随后 discovery 核安装身份链。

使用本操作实际来源。历史哈希或先前安装成功只适用于其输入，不认证相同版本号下被编辑的树。保留不匹配诊断并重新核变化来源，不能复制可信标签。

## 已安装来源的隐私

安装来源保留来源类型和内容身份，不暴露维护者机器/源码路径。公开仓库/归档不包含私有控制、数据库、会话、凭据和本地证据。通用占位/当前用户示例不表示可以公开真实路径。

## 本地资料保持本地

敏感定义/内容使用 Windows 当前用户 DPAPI，描述符限定所属、敏感性、用途和保留。加密不等于脱敏或跨用户恢复证明；派生来源需审阅和用途资格，撤回会停止依赖复用。

证据描述符绑定所属/目标、分类、敏感性、审阅、保留和允许用途。正文可允许 recovery，却不允许 derivation 或 Growth。复制到报告或改标签不能满足这些检查。

当前派生是控制端审阅、绑定准确来源并保留链的操作，不是自动脱敏器。复用前传递来源闭包核当前绑定与访问；来源撤回或到期可停止派生使用，即使字节仍完整。

DPAPI 在当前 Windows 用户配置下保护正文，不认证文本已脱敏或可公开，也不证明跨用户恢复。加密之外仍需原用途检查和宿主权限。

## 修改前审阅

Grant 绑定主体、资源、效果和当前任务版本，服务核依赖、预算、epoch 与准入。保留前像；UNKNOWN 沿原身份对账，不盲重试。受管 fencing 不排除任意外部编辑器。除输出外，也保护命令参数/历史中的秘密。

受管适配器在边界核准确任务/Grant/资源/效果及当前 lease/epoch，能拒绝旧主体或变化文件，但不证明机器上其他程序已停。影响目标时还须核外部编辑器/服务写者。

更新保全打开后当前文件前像，写前比较哈希。结果未知时核原操作及真实目标，不能换主体/ID 执行同效果绕过拒绝。恢复记录保留消耗和迟到观察。

发布也应审阅准确暂存路径与来源身份，排除私有资料，再核托管结果。仓库推送授权不允许导出工作区数据库或原验收正文。

## 保留与恢复

保留 binding/source-seal、原验收、未知效果和必要备份。年代或候选名不能证明可清理。恢复保持在 v2 内，对账后续工作和消耗，不复活旧权限。

## 报告安全问题

通过[仓库](https://github.com/SssoGin/MALTS)提供最小脱敏复现，不附密钥、原会话或受保护正文。见[状态合同](V2_STATE_CONTRACT.md)。

## 受管采用边界

`legacy-adoption-preflight` 在持久准备前检查所属根内管理布局或显式外置布局，以及 Windows 控制输入支持范围；目录关系有效不产生写入权限。`legacy-adoption-apply` 默认只预览，正式应用绑定准确计划哈希及当前运行时，并使用真实来源封印、Windows 文件保护与 SQLite 定义重验。内置模式只覆盖审阅的 MALTS 控制输入和旧事务准入，不隔离任意外部应用或接管业务根。

失败时保留原采用 ID、计划、所属封印和私有交接证据；不能换 ID 重放或删除 binding 来恢复旧权威。`workspace` 对旧来源、未绑定导入库和封印恢复现场分别给出迁移、采用与恢复诊断；已采用入口重核 Project/计划/Task/依赖并报告 `LONG_PROJECT`、`phase_ready` 和阻塞原因。该就绪仅为治理条件，不签发 Grant、不证明业务验收。跨根业务效果须另行核准资源与适配器。完整步骤见[采用与升级](V2_PREVIEW_USAGE.md#v2-migration)。

## 工作区管理数据与迁移

普通新工作区通过 `workspace-init` 默认将任务库、受管证据和恢复资料置于所属 `.malts` 目录，显式外置布局继续受支持。安装更新不搬动已有项目。健康已采用库可经只读计划、备份恢复、当前效果审查和正式前向切换重定位；新 epoch 不恢复旧授权或验收，也不自动激活 Phase。旧库、外部历史引用和来源封存按实际依赖保留。操作与限制见[工作区管理与状态库重定位](MANAGEMENT_AND_RELOCATION.md)。
