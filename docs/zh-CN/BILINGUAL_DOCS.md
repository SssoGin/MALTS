# MALTS 双语文档与模板

英文与简体中文指南描述同一 MALTS 产品，当前为 **2.0.0**。

## 用户文档

README.md 与 docs/ 提供英文指南，README.zh-CN.md 与 docs/zh-CN/ 提供对应中文指南。章节用途、示例、参数和限制相对应；技术事实以实现及实际证据为依据。

英文和中文入口引用同一工作流与准确命令合同。docs/zh-CN 的相对指南链接保持在中文文档集，源码/schema 链接指向共享包；读者选择语言不意味着选择另一套实现或安装。

例如 ToolRootDeepSeekHarness 与宿主身份 deepseek-harness 在双语中保持准确拼写。翻译标识或添加中文命令别名会使说明不可执行；用途用中文解释，命令标识保持原文。

## 运行模板

runtime/EN 和 runtime/CH 保存 Agent 模板/清单。稳定机器字段、命令和状态代码不翻译；结构检查不证明翻译质量。

## 标准项目文件

项目叙述与手工备注保留原语言。已采用工作区的执行事实由所选库/服务维护；叙述控制和计划作为来源/视图，不另建本地化状态。

目标、计划、手工备注和观察可使用项目语言，机器标识、状态代码和来源哈希保持准确。翻译引文是阅读辅助，不替代证据或计划绑定的原字节。

翻译当前视图时保留来源身份和任务版本；来源改变后，复用前按新事实审阅译文。不能分别维护英文和中文队列，否则接续与验收没有唯一责任来源。

## 不重复的内容

不因翻译复制状态库、操作身份、预算、验收、凭据或原始证据。完整翻译报告/交接仅在明确请求时生成。

## Agent 行为

按当前用途读取一种适用语言，保全原写内容。关键措辞以实际合同解决，共用协议修改时审阅双语。

说明使用所选指南语言，效果使用运行时准确字段。译文与已加载动作合同冲突时，执行前核参数 schema 和实现；语言偏好不改变宿主权限或状态语义。

结构检查比较标题、路径和所需协议词，语义审阅检查前置、结果、故障处理及限制是否对应。前者通过不证明后者。运行模板编码与原字节哈希遵循真实合同，不能随编辑器自动规范化。
