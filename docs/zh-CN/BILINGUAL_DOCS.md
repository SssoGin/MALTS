# MALTS 2.0.0 双语文档与维护关系

## 1. 正式来源

README.md和docs/为英文参考，README.zh-CN.md和docs/zh-CN/提供对应简体中文说明。两种语言描述同一版本、机制、命令与支持边界；实现、运行合同和实际验证决定技术事实，翻译不建立另一份状态。

## 2. 语言与项目事实

文档可选择任一语言，Task目标和用户手工内容保持原语言。命令、字段、ID、状态及Schema不翻译；runtime/EN和runtime/CH保留各自模板与检查清单。按用户语言生成阅读视图，不能批量翻译或复制状态库。

## 3. 历史与验收资料

当前指南说明2.0.0；CHANGELOG历史发布保留原版本和时间。派生说明须记录当前来源；原验收回执、hash和备份记录不能为了文档一致而改写。阅读副本变化不被旧回执自动认证。能力、安装、宿主和业务验收分别描述。见[设计](CORE_DESIGN.md)和[概览](SYSTEM_OVERVIEW.md)。
